# Python Basics – Prompt Engineering Assignment

## 📌 About the Repository

This repository is part of my **Prompt Engineering learning journey**.

The assignment focuses on using **LLMs (Large Language Models)** to assist with basic Python programming tasks and to understand how prompts can be used effectively during software development.

The repository was developed through **three main commits**, where each commit represents a different stage of the assignment.

## 🎯 Assignment Objectives

* Practice basic Python programming.
* Convert simple programming logic from C into Python.
* Understand how an LLM can assist with code generation.
* Learn how to write clear and specific prompts.
* Use an LLM to review and audit project documentation.
* Understand the importance of maintaining a clear Git commit history.

## 📂 Repository Contents

The repository contains basic Python programs developed as part of the assignment:

* Factorial program
* Fibonacci program
* Student structure program
* `README.md` documentation

This demonstrates how prompt engineering can be used not only for generating code, but also for **reviewing and improving software documentation**.

## 🤖 Use of Prompt Engineering

A major part of this assignment was understanding how an LLM can be guided using a specific prompt.

For example, prompts were used to instruct the LLM to act as a Python programmer and generate Python implementations from existing C programs.

The process was not limited to code generation. The LLM was also used during the final commit to **audit and improve the README file**.

This helped demonstrate two different applications of Prompt Engineering:

1. **Code Generation** – generating Python programs from given programming logic.
2. **Documentation Audit** – reviewing and improving the README using an LLM.
